# TRPG Notion Converter

코코포리아와 Roll20의 HTML 로그를 일반 문서처럼 보이는 Notion용 Markdown으로 변환하는 브라우저 기반 도구입니다.

## 사용법
1. `index.html`을 브라우저에서 열거나 GitHub Pages에 배포합니다.
2. 로그 HTML을 업로드합니다.
3. 화자를 PC/NPC/나레이션으로 분류하고 이니셜을 확인합니다.
4. 변환 결과를 검토한 뒤 Markdown을 다운로드합니다.
5. Notion에서 Markdown 파일을 가져옵니다.

## 주요 기능
- PC 영문 이니셜 자동 생성 및 편집
- NPC 무기명 대사, GM/KP 나레이션 문단화
- 주사위 판정 텍스트 보존
- 250개 메시지마다 일반 문서형 제목 순환 삽입
- 로컬 브라우저에서 파일 처리 (서버 업로드 없음)

## 주의사항
코코포리아/Roll20의 모든 HTML 변형에서 검증된 것은 아닙니다. 특히 주사위/메시지 누락 여부는 원본과 비교해 주세요. HTML 파일만 업로드하며 실제 개인 로그는 공개 저장소에 올리지 마세요.
